# Revisión de fluidos y réplica — 2026-10-31

Base: `d6e90c8ca35aed2597ab85d95a8a950326d198cd`, rama `26.2`.

## Cambios

- La malla consulta las microceldas de una cavidad vecina para no emitir caras
  internas donde ambas contienen el mismo fluido. Las fronteras con aire, otro
  fluido o datos de vecino ausentes siguen visibles.
- La clave de geometría incluye las seis cavidades vecinas. Al instalar una
  réplica distinta o retirar una entidad con cavidad, se solicita reconstruir
  los contenedores vecinos del cliente sin cargar chunks adicionales.
- Una réplica que llega antes de que el cliente cargue su chunk ya no se
  descarta silenciosamente: se conserva la solicitud de resincronización hasta
  que se cargue, con la misma caducidad de 60 segundos para posiciones ausentes.
- Se añadieron casos de límites en las seis direcciones; sus fuentes compilan.

## Decisiones y límites

El cambio oculta caras compartidas entre contenedores NMG, sin aproximar la
geometría ni eliminar agua. No suaviza la malla de 1/16 ni altera el algoritmo o
la cadencia de propagación. La unión con fluido nativo, la ordenación de
transparencias, el comportamiento en carga/descarga de chunks y la apariencia
real de la escena de la captura siguen pendientes de pruebas ejecutadas. No se
consideran resueltos todos los posibles fallos de fluidos ni del mod.

Java 25 y Gradle 9.2.1: `compileJava compileTestJava compileValidationJava`
correcto. Comprobaciones estáticas de recursos, matriz y sintaxis correctas. No
se ejecutaron tests Java ni se inició Minecraft; las pruebas visuales,
multijugador y de comportamiento permanecen pendientes.
